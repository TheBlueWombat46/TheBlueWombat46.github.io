MTG Pack EV Tool

An expected value model that answers a game store owner's question: is a Magic: The Gathering booster pack worth more sealed, or opened and sold as singles?

  1. Scryfall APILive prices for every printing in a set
  2. Booster modelCard counts and pull rates per pack slot
  3. Realizable valueAfter fees, discounts, shipping and a minimum listing price
  4. DecisionExpected profit and ROI per pack

Checking the output against official product contents turned up two errors: a column reference that zeroed out most card values, and Collector Booster cards inflating draft booster value. I found and fixed both.

Read the code and write-up on GitHub

Data and automation: Google Sheets, Apps Script, REST API

Reading past the average

Company data showed red and pink products declining. Broken down by subdepartment, they were only stocked in 2 of 8, and where they were stocked they earned 32% of sales from 16% of the products. The decline was about availability, not demand, so we expanded them.

Tools people use

I built an Excel tool that turns a product number into a finished display sign, cutting each one from about 4 minutes to 30 seconds. It is now being pitched for company-wide use. A second script formats a weekly department report in a quarter of the time, and my district manager asked for a copy.
